# Simulasi Optimasi Logistik - CVRP Simulator

## Deskripsi Proyek
Aplikasi web untuk menyelesaikan **Capacitated Vehicle Routing Problem (CVRP)** pada distribusi minyak goreng CV. Bima Laras Khatulistiwa. Mengimplementasikan tiga algoritma kecerdasan buatan:
- **Hill Climbing** (Simple, Steepest-Ascent, Stochastic)
- **Simulated Annealing** dengan cooling schedule
- **Genetic Algorithm** dengan elitism
